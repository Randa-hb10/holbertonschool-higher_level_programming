# SQL - Introduction

## 📋 Description

This project introduces SQL and MySQL basics, including database concepts, SQL queries, and basic data operations.

## 🎯 Learning Objectives

* Database and relational database concepts
* SQL meaning and MySQL usage
* Creating and managing databases and tables
* Performing CRUD operations (SELECT, INSERT, UPDATE, DELETE)
* Using subqueries and MySQL functions

## 🛠️ Requirements

* Ubuntu 22.04 LTS
* MySQL 8.0
* SQL keywords in uppercase
* Each query includes a comment
* Files end with a new line

## 📁 Files

SQL scripts implementing database creation, table management, data manipulation, aggregation, and filtering tasks.

## 🚀 Usage

```bash
# Run a script
cat file.sql | mysql -hlocalhost -uroot -p
```
