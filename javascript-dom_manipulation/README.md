# JavaScript DOM Manipulation

## Description
This project covers basic JavaScript DOM manipulation, event handling, and fetching data using APIs.

## Files
- 0-script.js: Change header color to red
- 1-script.js: Change header color on click
- 2-script.js: Add class `red` to header
- 3-script.js: Toggle between `red` and `green`
- 4-script.js: Add new list item
- 5-script.js: Update header text
- 6-script.js: Fetch Star Wars character
- 7-script.js: Fetch Star Wars movies
- 8-script.js: Fetch "hello" translation

## Technologies
JavaScript, DOM, Fetch API

## Requirements
- Chrome browser
- No `var`
- Semistandard style
